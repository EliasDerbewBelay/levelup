# Level Up Training Institute Public Assets Directory

This directory is organized for production images:

```text
public/
├── images/
│   ├── courses/        # Course promotional banners & curriculum infographics
│   ├── instructors/    # Verified faculty headshots (recommended: 400x400px JPG/WebP)
│   ├── events/         # Workshop & seminar flyers (recommended: 1200x630px WebP)
│   ├── gallery/        # High-res photography of Atika Building campus facilities & labs
│   └── blog/           # Editorial cover illustrations and diagrams
└── logo/               # Brand vectors (SVG) and icon marks
```

All UI components in the codebase are already prepared to ingest image files placed here.
